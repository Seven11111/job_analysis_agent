## [0.2.0] - 2026-10-14

### 核心产品能力

- 提供本地单用户求职工作台：岗位搜索与管理、自定义投递状态及时间线、个人画像、在线简历和附件简历解析。
- 接入 job-pro 校招实习岗位来源（适配版本支持的 50 家公司）、需官方登录的 BOSS 只读搜索，以及 Offer 先生校招资讯查询；搜索结果由用户确认后保存。
- 岗位链接支持通用公开页面读取与证据约束提取；岗位详情可使用 LiteLLM 生成结构化匹配分析。
- Agent 支持多轮 SSE 对话和本地历史记录，可调用岗位、状态、画像、简历、工作台、推荐、订阅及校招资讯能力；有副作用的操作须经持久化确认卡片。

### 求职工作台 2.0

- 增加基于真实岗位记录的投递看板、求职待办、面试日历和可追溯统计。
- 智能岗位推荐结合已确认的求职偏好与在线简历，提供可解释的匹配依据、技能差距和未知项；反馈仅作用于本次搜索，不自动修改画像或保存岗位。
- 岗位订阅支持保存搜索条件、手动或定时查新、去重、运行历史和短期结果预览；用户确认后才写入岗位库，不发送外部通知。

### 体验与稳定性

- 支持省份分组城市多选、岗位管理筛选与分页、状态时间线维护、订阅频率编辑和北京时间展示。
- Agent 搜索遵守岗位搜索页已启用的来源范围，并支持按已启用来源指定公司、城市和关键词。
- 改进 BOSS 登录状态复用、旧版搜索响应兼容、页面布局、跨域开发配置及公开招聘页面读取安全边界。
- job-pro 默认公司范围覆盖适配版本支持的 50 家公司；真实 Provider 的可用性仍取决于本机配置、登录状态及来源站点。

### 验证

- 离线测试 132 项通过；前端 lint 与 production build 通过。
- 在临时数据库验证迁移从 0004 升级至 head、降级回 0004 后再次升级至 head。
- 真实 LiteLLM SSE Agent 端到端单轮自测：12/12 场景通过、11/11 工具序列符合预期、3/3 搜索参数正确。该结果是小样本本机观测，不代表线上成功率或服务等级。
